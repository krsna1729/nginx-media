Sender CPU per delivered Gbit/s (lower is better)

Normalized efficiency metric: CPU cycles consumed divided by receiver-verified throughput. Allows direct regression tracking across commits on matching hardware.

Highest passing rung (higher is better)

Maximum destination count where all receivers maintained ≥95% of reference delivery without stream corruption or packet drops.

Hardware Runner Isolation

Benchmarks run on shared GitHub Actions runners with varying CPU architectures (AMD EPYC vs Intel Xeon). Use the Hardware filter above to compare commits on identical hardware.

Why are there *-srt-reference calibration rungs?

Mixed ladders (e.g. 95% RTMP + 5% SRT) round client counts to whole integers. At 1 destination, 5% rounds to 0 SRT receivers. The harness runs a 1-destination pre-calibration test (*-srt-reference) first to measure 100% SRT reference throughput for the ladder.
